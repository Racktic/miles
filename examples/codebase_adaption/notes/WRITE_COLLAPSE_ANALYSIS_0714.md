# WRITE 记忆坍缩归因分析(2026-07-14,run swecl-4b-alogfix-formal)

## 现象
- 退化记忆占比(剥围栏后正文 <50 字符):rollout 0→13 = 1%→6%→9%→25%→19%→18%→16%→17%→22%→43%→41%→38%;
- 记忆长度中位:1408 → 68 字符(rollout_13);
- 同期 ACT 健康上行(mean_r 0.226→0.458 区间),wandb 表现为 `codebase_response/write_len_mean` 持续下降。
- 退化样例(轨迹原文,`<|im_end|>` 完整收尾非截断):裸提交命令 `echo COMPLETE_TASK_AND_SUBMIT_FINAL_OUTPUT`、单条查看命令、"zqa" 等垃圾串。
  例:`logs/swecl-4b-alogfix-formal/traj/train/rollout_5/ep_80/81/82_episode_train_10_10.json`。

## 归因(rollout 4-13,n=1377 个已训练 WRITE 样本,全部实测)

**结论:不是"垃圾凭内容拿高奖",是 delta reward 的结构性 bias × 行为先验耦合;
且记忆内容对下一题真实增益≈0,无反向拉力。坍缩是该设计下的必然结果。**

| 检验 | 结果 | 含义 |
|---|---|---|
| corr(R, gain_k) | **−0.736** | R(M_k)=gain(k+1)−gain(k) 中 −gain_k 主导:当前题越差 R 越正(均值回归 bias) |
| 分层后内容效应 | 失败层 R(退化)+0.227 vs R(正常)+0.231;成功层 −0.139 vs −0.153 | 控制当前题结果后,**内容对 reward 无影响**(差 0.004~0.014) |
| 行为耦合 | P(退化\|失败)=**45%**,P(退化\|成功)=**9%** | 失败后倾向交白卷(base 行为先验,非 RL 所教) |
| 组内对照(122 混合组) | 下一题成功率差(退化−正常)=**+0.025** | 记忆内容对下一题≈无用 → 没有"好记忆被强化"的正通路 |
| **GRPO advantage(最终梯度方向)** | **退化 +0.294 vs 正常 −0.088** | 梯度系统性强化垃圾、抑制优质笔记 |

因果链:失败 → (a)倾向写垃圾 + (b)必拿高 R(均值回归)→ 组内比较中"失败副本的垃圾"
压过"成功副本的好笔记" → 逐轮强化;内容无用(第 4 行)→ 无对抗力量。

解析性排除:baseline 错配不构成组内 bias(同组共享题序,baseline 差进组均值被 GRPO 扣除)。

## 修复方向(下次实验;2026-07-14 晚经用户质询修正两处)

**事实修正**:训练题序是 **5+5**(同仓库 5 连题 ×2,如 astropy×5+pydata×5;逐行核实
formal_episodes.jsonl),不是 9+10(那是 heldout eval 套件)。

1. **去掉 −gain_k 项**:R(M_k)=gain(k+1) 或 mean(gain[k+1..k+K])。"控制起点"交给 GRPO
   组内均值扣除(同组同题序,等价且无偏)——现公式相当于扣两次起点,第二次扣出 bias。
   **等价性(用户指出)**:窗口=1 时,WRITE 的组内 advantage 与下一题 ACT 的 advantage
   **完全相同**(baseline 组内常数,被均值扣除)——纯信用共享,无偏但不含新信息;
   窗口 K>1 时为后 K 题均值,不再等同单题 ACT。
2. **退化格式门槛**:正文 <50 字符 → R=min(R,0) 或负分,切断行为先验搭便车。
3. **根本问题(H3 细分后修正)**:按转移类型拆开,**同仓库转移**(记忆最该有用处,178
   混合组)退化 vs 正常记忆的下一题成功率差 = **+0.032 ≈ 0**;跨仓库转移(29 组)+0.029。
   即**连同仓库连续设计下,现阶段的记忆也没有可测的因果效应**——不是题序结构问题,
   是"写出的笔记未被下一题有效利用"。推论:仅修公式只能**止住坍缩**(梯度均值归零,
   WRITE 漂成中性),不会自发学出好记忆;需先让"好记忆→下一题更好"因果链存在:
   ACT 侧强化记忆引用引导 / 对"记忆被实际引用"做 shaping / 先 SFT 教会写有用笔记再 RL。
