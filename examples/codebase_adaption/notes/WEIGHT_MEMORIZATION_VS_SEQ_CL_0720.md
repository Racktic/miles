# 权重背题 vs 序列内持续学习:判别性证据链(2026-07-20)

> 待验证命题(用户提出):"就算设计激励信号奖励 WRITE 写好 memory,模型还是不依赖 memory,
> 因为模型把答案记在了参数里。"本文用五个互相独立的判别性检验,在无激励对照(actonly)与
> 两个已激励臂(downstream、gated-v3nothink)上完成验证。结论:命题成立。

## 1. 判别逻辑

"权重拟合单题"与"学会序列内 continual learning"有可分离的统计签名:

| 检验 | 权重背题的预言 | 序列内学习的预言 |
|---|---|---|
| A. 难题首曝成绩随训练时段 | 平(没背过就不会) | 上扬(通用/序列能力增长) |
| B. 同难度带内曝光梯度 | 高曝 ≫ 首曝 | 无梯度 |
| C. 题内配对(同题第1-2次 vs 第8+次被训) | 显著提升 | 无关 |
| D. 晚期同题题位配对(pos0-2 记忆空 vs pos8-11 记忆满) | 无差 | 晚位显著更好 |
| E. ≤6 步秒杀成功在零记忆处的富集 | 富集(纯权重默写) | 秒杀依赖积累,零记忆处稀少 |

混杂控制:6p6 设计刻意让易题高频复现(anchor)、难题稀少 → 曝光与难度相关。
对策:难度带用 `data/baseline_4b_textfmt.json` 的基座 avg@4 划分(易>0.2 / 中(0,0.2] / 难=0),
检验 B/A 在带内进行;检验 C/D 用题内固定效应(同题自比)彻底消去难度。
曝光计数 = 该题历史上不重复的 (rollout, episode) draw 数。

## 2. actonly(无 WRITE 激励对照,r0-85,16512 trial)

1. **难题首曝随训练:0.09 → 0.08 → 0.09**(n=688/224/152)——84 轮训练对"解决没见过的难题"零提升;
2. **难题带晚期曝光梯度:首/低曝 0.12 vs 高曝 0.33**(+0.21)——同难度,背过的题 2.75 倍成功率;
3. **题内配对:0.40 → 0.63**(+0.23,n=73 题)——逐题拟合曲线本身;
4. **题位配对(r≥48):0.68 vs 0.70(+0.015,n=41 题)**——序列内积累贡献为零;
5. **零记忆秒杀:占秒杀 16% vs 空记忆基率 8%**(2× 富集)。

## 3. 已激励臂(命题的正面检验)

downstream = 裸下游 R=reward[k+1];v3nothink = 严格格式门控 + v3 prompt(合规率已达 100%)。
两组代表"激励已尽力"的两种设计。

| 检验 | downstream(r≤52) | v3nothink(r≤44) |
|---|---|---|
| D. 题位配对(空记忆 vs 满记忆) | 0.41 vs 0.39(**−0.015**,47 题) | 0.40 vs 0.36(**−0.041**,22 题) |
| E. 零记忆秒杀富集 | **21%** vs 基率 8%(2.6×) | **29%** vs 8%(3.6×) |
| B. 难题带曝光梯度(晚期) | 0.06 vs **0.13**(2×) | 0.10 vs 0.13 |
| A. 难题首曝随时段 | 0.08→0.05→0.06(平) | 0.10→0.07→0.05(平) |

行为层独立佐证(v3nothink r40+ 三条记忆链逐字精读,2026-07-19):
- 格式合规 100%(格式门饱和),但**相邻记忆逐字继承 0/213 bullet、跨 repo 边界保留 48/48 episode 全为 0**;
- 继承率时间线:起点 45% → r20 12% → r40 0%(actonly 不训对照后期仍 36%)——**继承是被训练磨掉的**;
- ACT 对记忆的实质利用率 **3-6%**;39% 是"假引用"(嘴上 Based on the memory,内容实来自题干);
- 全场唯一确定的真实利用(pos7 记忆 → pos8 null-guard 类比,gain 0.72)拿到了 write_reward 0.95——
  信号系统能奖励真有用的记忆,但此类正例过于稀疏,推不动自举。

## 4. 与 heldout 4.8× 的调和

actonly iter_71 在 heldout 19 题(较易的陌生题)上 4.8× 基座——与检验 A 不矛盾:
涨的是**通用工具/流程技能**(procedural→权重),对"难的陌生题"无效(A 平线)。
完整画像:训练产出 = 单题记忆(主导,B/C)+ 部分通用流程技能(heldout 可见);
**"序列内经验→后续题目"通道 = 精确的零(D/E)——恰是 CL 目标本身**。

## 5. 结论与设计含义

1. **命题成立**:两种 WRITE 激励设计(真实下游信号 / 严格门控+优化过的 prompt)都无法让 ACT
   依赖记忆——记忆在当前数据上没有边际价值(答案在参数里),激励供给侧解决不了需求侧为零的问题;
2. **WRITE 侧 reward 工程不是当前约束瓶颈,数据层才是**。改进方向:制造"权重背不动"的场景——
   大题池低重复、部分 repo 只在序列内出现(权重没机会拟合)、题目间真实依赖链——让记忆成为
   唯一知识通道,ACT 才有理由消费,WRITE 激励才有传导对象;
3. 门控的教训通用化:**门控/激励只保护它测量的维度**(格式 100% 与继承 0% 同时成立);
   任何"希望模型保持的性质"必须显式进入被测量的东西,或由数据结构使其内生必要。
